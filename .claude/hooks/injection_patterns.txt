# Prompt-injection patterns for injection_scan.py (Jarvis's own list, not copied from anywhere).
# Format:  category  weight  id  flags  [triggers]  ::  regex
#   category: override | authority | exfil | credential | tool   (hidden-text signals are computed in code)
#   weight:   points added once per id; the hook warns when the total reaches THRESHOLD (4) in injection_scan.py
#   flags:    "-" or "neg" (= ignore the hit when "never/don't/do not/אל/אין/לעולם" comes right before it)
#   triggers: comma-separated lowercase substrings; the regex only runs near one of them (speed). "*" = always.
#             Every match of the regex MUST contain at least one trigger, or the pattern can silently miss.
# Regexes run case-insensitive + multiline on NORMALISED text: lowercased, zero-width/bidi chars and niqqud removed,
# Cyrillic/Greek look-alikes mapped to Latin, full-width letters folded, HTML entities decoded.
# A second pass joins s p a c e d letters, undoes l33t digits and %-encoding; base64 / hidden-tag / reversed text
# is decoded and scanned too. Single weak words get 1 point so ordinary mail ("שלח לי", "המנהל") stays quiet.
# Edit tip: some shells collapse a double backslash; prefer \x5c for a literal backslash.
